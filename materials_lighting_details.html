材质

材质通过透光、模糊、明暗与阴影建立前后关系。卡萨帝多终端界面以清晰、安静、可信为前提：材质负责区分内容与功能，阴影只负责表达真实的悬浮层级。

01

核心设计原则

材质不是装饰滤镜。先确定元素在任务中的语义与层级，再选择视觉表现；任何效果都不能牺牲状态识别、文本对比度和操作确定性。

内容优先

设备状态、环境数据和主要任务始终清晰。材质只能帮助理解，不得与内容争夺注意力。

语义选材

同一用途跨端使用同一材质角色，不以“更亮、更透明、更高端”作为选择依据。

克制分层

内容层保持稳定，功能层按需浮现。一个视图原则上只保留一个最高悬浮层级。

02

层级材质

针对家电屏、移动端、TV 与中控屏的高频场景，材质分为稳定内容层与临时功能层。透明度越高，信息承载能力越低；文本越多，材质越应接近不透明。

03

阴影的材质

阴影模拟统一、柔和的顶部环境光，用于说明元素离开承载面的距离。卡萨帝界面不使用阴影制造装饰性立体感；层级越高，阴影位移、模糊和扩散越大，但边缘始终克制。

0 · Flat 页面背景、嵌入式内容、普通列表
1 · Rest 按钮、可点击卡片的静态状态
2 · Raised 悬浮卡片、悬浮快捷控制
3 · Overlay 下拉菜单、底部面板、临时控制盒
4 · Modal 确认弹窗、关键告警、阻断式任务

阴影 Token 与层级行为规范表

层级 Token / 参数说明 使用场景 系统行为
0 · Flat shadow.0 none 页面背景、嵌入式内容、普通列表 依靠色差、间距或分隔线组织信息结构。
1 · Rest 0 1 3 / 8% 按钮、可点击卡片的静态状态 只提示可交互，不改变信息层级。
2 · Raised 0 4 10 / 8% 悬浮卡片、悬浮快捷控制 仅在元素确实离开承载面时出现。
3 · Overlay 0 10 24 / 12% 下拉菜单、底部面板、临时控制盒 背景降低竞争，前景焦点清晰。
4 · Modal 0 20 48 / 16% 确认弹窗、关键告警、阻断式任务 必须配合背景遮罩；同屏只能有一个。
04

使用与验收

规范设计师与开发团队在搭建 UI 与验收交付时的红线准则。

✓ 应该（Recommended）

  • • 先确定内容层级或功能层，再选择材质。
  • • 复杂背景上提高不透明度并验证对比度。
  • • 用 Solid 承载告警、数据和长文本。
  • • 让阴影、遮挡和焦点指向同一层级。

✕ 不应该（Avoid）

  • • 让整个页面和每张卡片都使用玻璃效果。
  • • 以透明度或阴影作为唯一状态提示。
  • • 在图片上直接放置低对比文字与图标。
  • • 给嵌入式列表和小图标添加悬浮阴影。
